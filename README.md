# Roadmap Control

Локальный трекер прохождения roadmap «Профессиональное создание AI-роликов и рекламы».
40 этапов основной программы (51 неделя), их разделы (темы, инструменты, задания) и пункты с галочками.
Всё про локальную генерацию (ComfyUI, ControlNet, LoRA, открытые модели, видеокарта) вынесено в
**дополнительный блок** из 3 этапов — он идёт по желанию и не учитывается в общем прогрессе.

## Запуск

Нужен только Node.js, ничего устанавливать через npm не надо.

**Вариант 1 — VS Code:** откройте папку `Control Website` (File → Open Folder) и нажмите **F5**
(конфигурация «Запустить Roadmap Control»). Сайт откроется в браузере сам.

**Вариант 2 — терминал** (в том числе встроенный терминал VS Code):

```bash
npm start
```

Адрес: http://localhost:4321 (если порт занят, сервер возьмёт следующий свободный, адрес будет в терминале).
Остановить сервер: `Ctrl+C` в терминале или Shift+F5 в VS Code.

## Где хранится прогресс

В файле `data/progress.json`. Перед каждым сохранением предыдущая версия копируется в
`data/progress.backup.json`. Кнопки «Экспорт» и «Импорт» в шапке скачивают и загружают прогресс
одним JSON-файлом, если нужно перенести его на другой компьютер.

## Что есть на сайте

- **Обзор** — общий прогресс, текущий этап, активность за 2 недели, блоки программы.
- **Этап** — все разделы с галочками. Можно отметить пункт, раздел целиком или весь этап.
  У каждого отмеченного пункта видна дата отметки. Внизу — поле для заметок по этапу.
- **Сегодня** — что отмечено за день (можно листать по дням) и ежедневная практика.
- **Постоянные задания** — ежедневные, еженедельные и ежемесячные пункты. Отметки сбрасываются
  сами в начале нового периода, история сохраняется.
- **Поиск** — по всем темам, инструментам и заданиям.

## Если roadmap изменится

Положите новый .docx в папку `AI ads` и пересоберите данные:

```bash
python3 tools/build_roadmap.py "../AI_video_roadmap_RU_v3.docx"
```

Отметки привязаны к позиции пункта (например, `s05-tasks-02`), поэтому если в этапе добавятся
или удалятся пункты, часть отметок внутри этого этапа может сместиться.
