# Личная панель

Локальная панель для контроля личного времени.

**Главная страница — расписание недели** в стиле Google Календаря:
- Основной режим (вариант 2 из расписания) стоит по умолчанию на каждой неделе. Любой день можно
  поменять: добавить задачу кликом по пустому месту, перетащить блок мышкой (в том числе на другой день),
  растянуть за нижний край, открыть кликом и поменять время, категорию, заметку, отметить «Выполнено».
  Изменённый день помечается «изменён», его можно вернуть к шаблону.
- «Шаблон недели» — редактирование основного режима (меняет все недели, где день не правился вручную)
  и просмотр плохого режима.
- «Сравнение режимов» — плохой режим (вариант 1) не ставится в календарь, а сравнивается с основным:
  сколько часов работы теряется и сколько уходит на «хуйню» за день и за неделю.
- На календаре видны события панелей: занятия, записи к врачам, созвоны, уроки вождения, а сверху —
  дедлайны университета и проверки задач Навигатора.
- «Все панели» — плитки со сводками, клик открывает панель:

- **Roadmap Control** (`/roadmap/`): прохождение roadmap «Профессиональное создание AI-роликов и рекламы».
  40 этапов основной программы (51 неделя), их разделы (темы, инструменты, задания) и пункты с галочками.
  Всё про локальную генерацию (ComfyUI, ControlNet, LoRA, открытые модели, видеокарта) вынесено в
  **дополнительный блок** из 3 этапов: он идёт по желанию и не учитывается в общем прогрессе.
- **Репетиторство** (`/tutoring/`): IT-школы → предметы, которые вы ведёте → занятия с датой, временем
  и заданиями для подготовки. Главный экран панели — ближайшие занятия по дням. Когда все задания
  выполнены, занятие становится «Готов к проведению»; «Проведено» отмечается отдельной кнопкой.
  Занятие можно сразу повторить на N недель вперёд.
- **Университет** (`/university/`): предметы → задания с приоритетом (высокий / средний / низкий)
  и дедлайном. Главный экран панели — все задания по срокам: просрочено, сегодня, завтра,
  ближайшие 7 дней, позже, без дедлайна. Фильтр по приоритету.
- **Навигатор** (`/navigator/`): созвоны, которые вы организуете (тема, участники, ссылка, повестка
  чек-листом, итоги), и задачи — себе или людям — с дедлайном проверки. Задачи сгруппированы по срокам,
  в боковой панели — у кого сколько задач.
- **Здоровье** (`/health/`): поликлиники → вкладки «Врачи», «Анализы», «Записи». К врачу или на анализ
  можно записаться; «Мои записи» показывают, когда и куда идти. Подготовка к анализу (натощак и т. п.)
  автоматически становится чек-листом записи.
- **Права** (`/rights/`): «Теория» — 40 билетов с галочками, «Практика» — уроки вождения с заданиями,
  которые нужно сделать перед уроком.

## Структура

```
index.html, home/      главный экран: расписание (home/app.js, исходное расписание —
                       home/schedule-default.js) и плитки панелей (home/tiles.js)
shared/                общие модули: список панелей (panels.js), каркас в стиле Roadmap Control
                       (shell.css, shell.js), карточка события с чек-листом (events.js),
                       хранилище (store.js), формы и даты (util.js), тема (theme.js)
panels/<id>/           каждая панель в своей папке
data/<key>.json        данные панелей (не попадают в git): schedule, progress, tutoring,
                       university, navigator, health, rights
server.js              локальный сервер, без зависимостей
```

Новая панель = папка `panels/<id>/` с `index.html` + запись в `shared/panels.js`.
Панель хранит данные через `GET/PUT /api/store/<key>` → файл `data/<key>.json`.

## Запуск

Нужен только Node.js, ничего устанавливать через npm не надо.

**Вариант 1 — VS Code:** откройте папку `Control Website` (File → Open Folder) и нажмите **F5**
(конфигурация «Запустить личную панель»). Сайт откроется в браузере сам.

**Вариант 2 — терминал** (в том числе встроенный терминал VS Code):

```bash
npm start
```

Адрес: http://localhost:4321 (если порт занят, сервер возьмёт следующий свободный, адрес будет в терминале).
Остановить сервер: `Ctrl+C` в терминале или Shift+F5 в VS Code.

## Где хранится прогресс Roadmap Control

В файле `data/progress.json`. Перед каждым сохранением предыдущая версия копируется в
`data/progress.backup.json`. Кнопки «Экспорт» и «Импорт» в шапке скачивают и загружают прогресс
одним JSON-файлом, если нужно перенести его на другой компьютер.

## Что есть в Roadmap Control

- **Обзор** — общий прогресс, текущий этап, активность за 2 недели, блоки программы.
- **Этап** — все разделы с галочками. Можно отметить пункт, раздел целиком или весь этап.
  У каждого отмеченного пункта видна дата отметки. Внизу — поле для заметок по этапу.
- **Сегодня** — что отмечено за день (можно листать по дням) и ежедневная практика.
- **Постоянные задания** — ежедневные, еженедельные и ежемесячные пункты. Отметки сбрасываются
  сами в начале нового периода, история сохраняется.
- **Поиск** — по всем темам, инструментам и заданиям.

## Если roadmap изменится

Положите новый .docx в папку `AI ads` и пересоберите данные:

```bash
python3 tools/build_roadmap.py "../AI_video_roadmap_RU_v3.docx"
```

Отметки привязаны к позиции пункта (например, `s05-tasks-02`), поэтому если в этапе добавятся
или удалятся пункты, часть отметок внутри этого этапа может сместиться.
